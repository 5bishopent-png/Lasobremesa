# Sobre Mesa

Official production site for **Sobre Mesa** — Mexican private dining and culinary events by Chef Adam Bishop.

- Production: https://www.lasobremesa.vip/
- Canonical domain: https://www.lasobremesa.vip/
- Hosting: Vercel
- Source branch: `main`

The site includes private dining and event services, chef credentials, sample menus, an event inquiry flow, responsive/mobile navigation, SEO metadata, structured data, sitemap/robots files, and the Chef Concierge integration.

## Production notes

Changes pushed to `main` are intended for production deployment through the connected Vercel project. Secrets and provider credentials must remain in Vercel environment variables and never be committed to this repository.

See `CONCIERGE_SETUP.md` for concierge, email, calendar, reminder, and owner-workflow configuration.
